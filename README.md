# GFX.Physics

`GFX.Physics` provides an optional native Silex 2D physics simulation and
standalone 3D convex geometry queries and a first 3D world for free body
motion. They are independent from windows, renderers, scenes, and ECS worlds.
The 3D world does not resolve collisions yet.

```text
silex install GFX.Physics
```
